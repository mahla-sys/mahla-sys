## 🚀 Featured Projects

### 1. Modular Event-Driven Trading Framework (MQL5 / Python)
*Status: In Active Development (Architecture Phase)*

A highly sophisticated, 3000-line algorithmic trading framework designed for Forex markets, utilizing an advanced **Event-Driven Architecture** to handle execution, risk management, and data logging.

*   **Central Event Bus ("Radio"):** Implemented a centralized communication hub that broadcasts system states (Filter verifications, Order Open/Close signals) to various independent manager modules, ensuring asynchronous and decouple execution.
*   **Component-Based Management:** Designed dedicated modules including a *Filters Manager* (handling 7-10 customizable market filters), an *Execution Manager* (Open/Close logic), and a *Maintain Manager* for dynamic position tracking (Trailing Stops, Trend Weakening analysis).
*   **State Management & Granular Logging:** Tracks **22 distinct data metrics** per trade for deep backtesting and statistical analysis.
*   **💡 Why it matters for Pro Traders:** This architecture ensures that risk management and stop-loss execution are completely isolated from signal generation. Even during high-volatility news events, the system guarantees zero execution lag and zero frozen orders.
